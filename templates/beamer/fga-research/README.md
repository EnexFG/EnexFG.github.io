# FGA Research Beamer Template

This is a reusable Beamer template aligned with the visual identity of the site.

Compile from this folder:

```bash
latexmk -pdf main.tex
```

Color roles:

- `FGAAubergine` (`#4A355D`): institutional structure, titles, navigation.
- `FGATeal` (`#254F55`): quantitative estimates and model elements.
- `FGACopper` (`#B66A32`): key findings and takeaways.
- `FGAPaper` (`#FBFAF7`): background.
- `FGABone` (`#E6DFD4`): grid lines and separators.
- `FGAInk` (`#182126`): main text.
